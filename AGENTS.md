# Project instructions

- Keep project work inside this folder. Inspect the current files before changing them.
- Read `README.md`, `docs/engineering.md`, and `docs/design.md` before implementing a feature.
- Keep changes focused on the requested outcome. Do not add speculative features, dependencies, or abstractions.
- Follow the selected framework's conventions once a stack exists. Update the README when setup or commands change.
- Preserve user changes. Keep credentials and personal data out of source, fixtures, screenshots, and logs.
- Verify changes with the available checks and relevant manual review. Report what was checked and any remaining limitations; do not claim unrun checks passed.
- Ask before connecting to a Git host, pushing, publishing, or changing external services.

These are project instructions, not a custom skill. Extend ordinary documentation as the project grows.
